:: SYSTEM GUIDE ::

1. TIMER: 输入任务和时间，点击 START。若倒计时结束前完成，请务必点击 DONE。

2. DASHBOARD: 左侧集成了天气、待办、倒数日、日志和下班倒计时。移动端可点击按钮折叠。

3. AUTO-SAVE: 系统将在设定时间（默认00:00）自动保存昨日数据并刷新。

4. ZEN: 点击时间数字或 ZEN 按钮，隐藏所有干扰。
